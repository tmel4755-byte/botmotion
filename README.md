# Бот-напоминание (botmotion)

Telegram-бот для создания и управления напоминаниями с поддержкой разных часовых поясов.

## Особенности

- Создание напоминаний с настройкой времени
- Поддержка различных типов повтора (однократно, ежедневно, еженедельно)
- Настройка часового пояса для корректного времени
- Управление всеми напоминаниями пользователя
- Административные функции (для администраторов)
- Интерактивное меню с подтверждением действий

## Установка

1. Клонируйте репозиторий:
```bash
git clone <url_to_repository>
cd botmotion
```

2. Установите зависимости:
```bash
pip install -r requirements.txt
```

3. Создайте файл `.env` в корне проекта и укажите токен бота:
```
BOT_TOKEN=your_bot_token_here
ADMIN_ID=your_admin_id_here
```

4. Запустите бота:
```bash
python -m bot.main
```

## Функциональность

### Для пользователей

- `/start` — начать взаимодействие с ботом
- Создание напоминаний с выбором времени и типа повтора
- Просмотр всех активных напоминаний
- Удаление отдельных напоминаний
- Изменение часового пояса
- Настройка уведомлений

### Административные функции

- Просмотр статистики использования
- Управление пользователями
- Отключение всех напоминаний (в разработке)

## Технологии

- Python 3.8+
- aiogram 3.5.0 (библиотека для Telegram Bot API)
- aiosqlite (асинхронная работа с SQLite)
- pytz (работа с часовыми поясами)
- python-dotenv (управление переменными окружения)
